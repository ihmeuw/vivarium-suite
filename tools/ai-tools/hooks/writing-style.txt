Prose for people in this project is plain technical English. Sentences are short, in the active voice, and in simple tenses. Each thing has one name. The text has no semicolons, contractions, Latin abbreviations, or metaphors. Code identifiers and paths are in backticks. A guess or a judgment is marked as one, and a reason that the source does not give is not stated as fact. Code and quoted text keep their own conventions.
