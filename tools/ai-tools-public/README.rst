IHME Dev AI Tools (``viv-public``)
==================================

Generic AI-assisted developer workflows for Claude Code, usable by any IHME
team in any repository. Extracted from the SimSci team's ``viv`` plugin
(MIC-7220); carries no SimSci- or vivarium-specific process.

.. note::
   Full documentation (component catalog, installation, security model) is
   filled in in the docs pass of the split PR.

Installation
------------

.. code-block::

   /plugin marketplace add ihmeuw/vivarium-suite
   /plugin install viv-public@vivarium-ai-tools
