==========================
Vivarium Testing Utilities
==========================

This package contains tools for the Institute for Health Metrics and Evaluation's
Simulation Science Team to use in testing simulations. It is one of the libraries
in the `vivarium-suite <https://github.com/ihmeuw/vivarium-suite>`_ monorepo,
named after our `Vivarium <https://vivarium.readthedocs.io/en/latest/>`_
microsimulation framework.
