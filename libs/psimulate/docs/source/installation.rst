Installation
============

You can install this package with

.. code-block:: console

    pip install vivarium-psimulate

To submit jobs on the IHME cluster, install the ``cluster`` extra, which pulls
in Jobmon from IHME's internal PyPI mirror:

.. code-block:: console

    pip install "vivarium-psimulate[cluster]"
