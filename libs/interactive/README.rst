====================
Vivarium Interactive
====================

.. image:: https://badge.fury.io/py/vivarium-interactive.svg
    :target: https://badge.fury.io/py/vivarium-interactive

.. image:: https://readthedocs.org/projects/vivarium-interactive/badge/?version=latest
    :target: https://vivarium-interactive.readthedocs.io/en/latest/?badge=latest
    :alt: Documentation Status

This library provides ``Simulation``, a way to run and inspect a vivarium
simulation interactively, for example in a Jupyter notebook. It steps the
simulation on demand and exposes the population, pipelines, resources,
and results for inspection.

**Supported Python versions: 3.11, 3.12, 3.13**

You can install ``vivarium-interactive`` from PyPI with pip:

.. code-block:: bash

   pip install vivarium-interactive

or build it from source by cloning the monorepo and installing this package:

.. code-block:: bash

   git clone https://github.com/ihmeuw/vivarium-suite.git
   cd vivarium-suite
   pip install libs/interactive

For broader monorepo development setup, see the monorepo README at
https://github.com/ihmeuw/vivarium-suite.

`Check out the docs! <https://vivarium-interactive.readthedocs.io/en/latest/>`_
