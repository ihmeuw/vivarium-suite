============================================
Vivarium Automated Verification & Validation
============================================

This package provides tooling for automated verification and validation (V&V)
of `Vivarium <https://vivarium-engine.readthedocs.io/en/latest/>`_ simulations.
It is one of the libraries in the
`vivarium-suite <https://github.com/ihmeuw/vivarium-suite>`_ monorepo, maintained
by the Institute for Health Metrics and Evaluation's Simulation Science team.
